# 博士扩列档案

明日方舟扩列卡填写器，免费、非商业。在浏览器本地填写信息、拖动七条偏好滑块、切换阵营和自定义语录，添加头像、角色与微信／QQ 二维码，导出 PNG 图片。

[在线使用](https://tiny.leisiyu.dev/projects/arknights-card/)

## 使用

选择阵营后填写档案。语录可自行编辑，也可恢复阵营默认。将二维码图片或截图拖入对应位置，自动识别裁剪；无法识别时可手动框选。完成后导出图片。

填写信息与上传图片只在当前浏览器内存中处理，不发送到服务端；刷新页面会清空。分享前检查导出图包含的个人信息。

## 本地运行

安装 Node.js 22 或更新版本后运行 `npm run preview`，打开终端显示的网址。无需安装运行依赖。测试使用 `npm test`；测试相关工具及夹具位于 `test/`。
