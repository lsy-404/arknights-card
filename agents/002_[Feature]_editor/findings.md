# 调研记录

- 参考图结构：白底黑线档案布局，头部编号、醒目昵称/头像区、基础资料和双列详细偏好。仅参考版式，不使用图中像素。
- 项目使用纯静态 HTML、CSS 和 ES modules；图像均在浏览器本地处理。
- 外部素材与 factions/operators 数据由主协作者提供，二维码模块接口待同步。
- 滑块采用 0–100 的原生 range，保留连续拖动手感，并将每项偏好绘到预览对应轨道。
- 阵营语录在未自定义时随阵营切换；手动编辑后跨阵营保留，支持一键恢复当前阵营默认语录。
- Tiny 元标签命名为 `home-url`；按其 `content` 有值时显示返回链接。
- 二维码成功识别后也保留手动裁切/调整入口，避免自动识别边界不合意时无法修正。
