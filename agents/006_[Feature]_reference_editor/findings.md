# 调研
用户明确纠正自拟语录，要求优先采用原模板的游戏阵营原句、切换时同步。参考仍仅用于文本与坐标，不复用像素。此轮按原1640x2360坐标重建可直接编辑的档案，交互与导出共享坐标。
界面与Canvas模块由版式分支负责，富文本采用成熟Quill本地vendor，纯Canvas格式绘制独立模块。语录分支核对25阵营两条原句。主协作者获取完整PRTS干员列表与本地头像并集成、验证、发布。
现有主仓库与Tiny工作树clean，保留原主checkout。沿用固定Windows worktrees根，不删移现有工作树。用户要求完整干员搜索已纳入本次范围。

- 直接HTTP请求PRTS返回403/超时，改用可正常访问的浏览器页面公开DOM和原生资源导出。200条分页受资源性能缓冲上限影响，改50条分页并分标签采集后434项全部成功。

- 原图关键文字暗像素实测：B101 (1427,190)-(1514,228)、Doctor (198,447)-(330,475)、About me (133,1099)-(308,1128)、motto (295,607)-(545,646)；字体候选不能冒称已识别原字体。
- 综合验证检出二维码count切换残留、空编号回落B101、超长默认原句按70/90字符截断、连续拼音无法匹配、画布二维码框缺drop事件、hidden被display规则覆盖；全部作为本轮修复范围。
- 原图横线Object.values传参因对象重复y键只有三个坐标值，导致底线未画；改为显式取x1/y/x2/y后测量实际PNG。
- 字号超过字段高度时Canvas整行跳过与DOM裁切不一致，富文本分支改为画可见部分并验证200px字在64px框仍可见。
- 4196预览启动时端口占用，根集成预览改4206；部分带方括号审计路径被PowerShell通配解析，后续读取统一LiteralPath。
