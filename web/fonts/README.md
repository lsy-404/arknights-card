# Fonts

- Arimo: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/arimo), SIL Open Font License 1.1, see Arimo-OFL.txt.
- Noto Sans SC: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notosanssc), SIL Open Font License 1.1, see NotoSansSC-OFL.txt.

The variable fonts are distributed as WOFF2 subsets. Arimo contains Latin, Greek, Cyrillic and common symbols. Noto Sans SC includes GB2312, kana, punctuation, and all characters in the included operator catalog, faction quotations and interface. Other characters use the browser's sans-serif fallback. The font licenses apply separately from the application license.
